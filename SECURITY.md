# Security Policy

## Supported Versions

| Version | Supported          |
| :---    | :---:              |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in OmniLauncher:
1. **DO NOT** open a public GitHub issue.
2. Please submit the report through GitHub's [Private Vulnerability Reporting](https://github.com/Tmub1k/TMlauncher/security/advisories/new) or directly reach out to the maintainers.
3. Include detailed steps to reproduce, impact analysis, and proof-of-concept if available.

We strive to review and respond to reports promptly.
